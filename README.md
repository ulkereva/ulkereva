## About This Portfolio

This repository documents my work as a **QA Engineer** across **manual testing, API testing,
and SQL data validation**, with test automation skills actively in development.

The bug reports are based on **real testing engagements** and have been **anonymized** —
product names and sensitive details removed, while preserving the testing methodology,
severity analysis, and reporting structure.

Together these sections tell one story: **a tester who can design coverage, find and
communicate defects clearly (ISO 29119), validate data, and is building toward automation.**
